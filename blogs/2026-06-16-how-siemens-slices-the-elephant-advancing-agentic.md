Siemens built Knowledge Fabric, an AI system for automating software development across industrial codebases with hundreds of millions of lines of legacy code, using Spanner Graph, the Google Agent Development Kit, Gemini API, and Anthropic Claude Code. The "slicing the elephant" methodology breaks complex refactoring into smaller agent-led tasks handled by specialized search, user story, architecture impact, task breakdown, and coding agents, with pilot results showing dependency analysis that previously took days completing much faster.
