Curve Financial used BigQuery Graph's native graph query language to simplify multi-hop network analysis for identifying fraud rings, modeling users as nodes and shared identifiers as edges. The approach achieved about 72% fraud-detection accuracy and saved an estimated $12 million in 2025.
