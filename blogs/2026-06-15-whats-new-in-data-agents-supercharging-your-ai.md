Google expanded its Agentic Data Cloud with Conversational Analytics now supporting BigQuery, Lakehouse, AlloyDB, Spanner, Cloud SQL, and Looker, plus new data agents including Data Engineering, Data Science, Database Observability, Database Onboarding, Looker Dashboard, Data Insights, and Deep Research agents. Developer tools include the Data Agent Kit, Managed MCP Servers for various databases, and MCP Toolbox reaching production-ready status.
